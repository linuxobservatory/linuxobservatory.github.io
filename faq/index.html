18 COMMON QUESTIONS

Open a question.

Do I need Linux to watch these videos?

No. The recordings are public videos. A Windows, macOS or phone viewer can watch and learn without installing Linux.

What does Proton do?

Proton is a Steam compatibility tool that helps many Windows games run on Linux. Compatibility depends on the game, version and system.

Does Linux Observatory test only Windows games?

No. The operator also investigates Linux-native titles. Each recording should identify its runtime where that is documented.

Why are numbers visible over gameplay?

Performance overlays expose information such as FPS, frame time and resource usage. They help connect the visible experience to the measured conditions.

Is a higher FPS always smoother?

No. Uneven frame delivery can cause a perceptible hitch even with a high average. Frame-time behavior matters.

What is frame time?

The time associated with producing or presenting a frame, generally shown in milliseconds. A large excursion can signal an unusually slow frame.

What is a 1% low?

A summary relating to the slower portion of frames. Exact calculation methods differ, so the tool and methodology matter.

What is Mesa?

Mesa is an open-source collection of graphics drivers and related components widely used on Linux.

What is RADV?

RADV is Mesa’s Vulkan driver for many AMD GPUs, including RDNA-generation hardware.

What is Gamescope?

Gamescope is a compositor that can manage a game in a virtual display environment, including different render and output resolutions.

Is a 16K test meant to be playable?

Usually not. It is an experiment intended to observe behavior under unusually high rendering load.

Does 16K mean the monitor is 16K?

No. The internal render target can exceed the physical display resolution; the output may be scaled to a 4K screen.

Can one video prove a driver regression?

One run can show a symptom. Demonstrating a regression normally requires comparable software conditions, repeated testing and other possible causes considered.

Is this a conventional benchmark site?

Not primarily. It documents observations. Controlled comparisons are a more specific category with stricter evidence requirements.

Why is the Linux distribution sometimes different?

The operator’s software environment changes over time. Fedora 45 is the latest reported distribution, not necessarily the distribution used in older recordings.

Can I request a game to test?

Use the official YouTube channel to suggest a game or technical question; suggestions do not guarantee future coverage.

Are the demonstrations on this website real FPS measurements?

The interactive frame-time example is explicitly synthetic. Real test claims are distinguished from illustrations and linked to source material where available.

Can I republish the footage?

Attribution preferences are documented, but no blanket reuse license is asserted. Ask the rights holder about formal permission.
