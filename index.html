ACTUAL WORKLOADS, OPEN FOR INSPECTION

What happens when 4K is no longer the limit?

At 32K-class rendering targets, the pixel workload becomes enormous. The interesting question is not whether it's a sensible way to play. It's what the game, graphics stack and memory system do when pushed there.

The recording shows one particular run. It does not, by itself, prove which component is responsible for every performance limit.
