THE GRAPHICS STACK / BEGINNER TRANSLATION

How a game reaches
your GPU.

A Windows game does not simply turn into a Linux game. Several layers work together to make its graphics instructions usable. Here’s the short version before the deep version.

A SIMPLIFIED PATH / WINDOWS DIRECT3D GAME ON AMD LINUX

The journey of a frame.

01
Game

Creates a frame and asks the graphics system to draw it.

↓
02
Proton / Wine

Provides Windows compatibility facilities so many Windows games can run on Linux.

↓
03
DXVK or VKD3D-Proton

For many Direct3D games, translates graphics calls into Vulkan. DXVK covers D3D 9/10/11; VKD3D-Proton targets D3D 12.

↓
04
Vulkan → Mesa RADV

Vulkan is the graphics API. RADV is a Mesa Vulkan driver for modern AMD GPUs, translating work into hardware-specific commands.

↓
05
Linux amdgpu driver → GPU → display

The kernel driver manages low-level hardware interactions; the compositor and display path determine how rendered frames appear.

Simplified schematic. Native Linux Vulkan or OpenGL games can follow different paths. Wayland/X11, Gamescope, OpenGL drivers and presentation details are omitted from this core diagram for clarity.

THE PARTS / PLAIN ENGLISH

What the names mean.

PROTON

The compatibility layer

Helps many Windows games operate under Linux. It includes Wine and other components, but compatibility varies by game and version.

MESA / RADV

The AMD Vulkan driver

Mesa is an open graphics-software project; RADV is one of its Vulkan drivers for AMD hardware.

DXVK / VKD3D

The translators

These translate Direct3D calls to Vulkan for many titles. Which translation layer is used depends on the game and configuration.

WAYLAND

The desktop display protocol

Part of how applications, desktops and displays coordinate. Not itself the game renderer.

GAMESCOPE

The compositor / virtual display

Can give a game a controlled virtual display size and then scale its output. Useful in some experimental setups.

MANGOHUD

The instrument panel

Makes FPS, frame timing and resource readouts visible in supported OpenGL/Vulkan applications.
